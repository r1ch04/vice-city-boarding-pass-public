讓下一站，成為你的收藏。

這是一個同人紀念登機證設計工具，不連接任何航空公司或票務系統。

  1. 在「旅客與航線」填入姓名，選擇或自訂出發及抵達機場。
  2. 在「航班細節」設定時間、登機門、艙等與行李資料。
  3. 挑選風格，或在「票面設計」修改航空名稱、語言與配色。
  4. 下載 3 倍解析度 PNG，或 240 毫米寬的 PDF 票面。

所有欄位均為自由創作內容。機場選單只提供名稱預設，不提供航班查詢；條碼為無法驗票的裝飾圖樣。

頁面不會自動保存資料。使用編輯器下方的儲存按鈕，可下載 JSON 設計檔，下次再載入繼續編輯。
