# DEPARTURE.｜罪惡城登機證設計室

以落日、棕櫚與粉紫色調呈現的繁體中文登機證設計工具。整個網站為靜態 HTML、CSS 與 JavaScript，不需要後端、資料庫或 API 金鑰。

## 功能

- 即時編輯旅客姓名、航線、機場、航班、日期、時間、座位、登機門、行李與訂位資訊。
- 繁體中文、英文與雙語票面。
- 棕櫚落日預設背景、收錄的官方截圖圖庫，以及使用者自行上傳 JPG、PNG、WebP。
- 背景縮放、水平位置、垂直位置與柔霧遮罩。
- 經典罪惡城、落日海岸、霓虹夜航三款色調，以及自訂文字主色。
- 票根、裝飾條碼、寄語與紀念票標示可各別開關。紀念票標示預設關閉。
- 下載 3600 × 1440 像素 PNG 或 240 × 96 毫米 PDF。
- 以 JSON 儲存／載入設計，包含自訂背景圖片。
- 響應式桌機與手機介面。

## 在本機使用

請以靜態網頁伺服器開啟專案，避免直接雙擊 HTML 造成瀏覽器阻擋圖庫與字型讀取。例如，已安裝 Node.js 時可執行：

```sh
npx serve .
```

接著開啟終端機顯示的本機網址。專案不需要建置或安裝應用程式相依套件。

## GitHub Pages

若帳號與儲存庫方案支援 GitHub Pages，可在儲存庫的「Settings → Pages」選擇「Deploy from a branch」，再選擇儲存此專案的預設分支與根目錄（`/`）。

網站入口為 `index.html`，所有檔案均使用相對路徑，適合部署到 GitHub Pages 的專案子路徑。部署前請確認你已授權公開網站及其中的素材；私人程式碼儲存庫與公開網站的可見性是不同設定。

## 檔案結構

```text
index.html           頁面與表單
style.css            基礎排版與響應式樣式
vice.css             罪惡城視覺風格
app.js               票面繪製、背景、圖庫、設計檔與匯出
gallery.json         截圖索引與原始素材網址
assets/              背景、截圖、縮圖與手寫字型
vendor/              本地打包的 Lucide 與 jsPDF
```

## 資料與隱私

旅客資訊與使用者自行上傳的背景圖片只在瀏覽器內處理，不會送到應用程式伺服器，也不會自動保存。關閉頁面前，可先下載 JSON 設計檔；設計檔包含填寫的資訊及自訂圖片，請自行妥善保管。

頁面會載入介面網路字型。背景圖庫是專案打包收錄的素材快照，不會即時同步官方網站更新。
